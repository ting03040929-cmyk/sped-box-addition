# 盒子畫圈接數加法 (國中特教班數學互動練習系統) 📦➔⭕

專為特教班學生個別化教學設計的「兩位數相加（第一個數 1~50 ＋ 後面的數 1~20）」互動式教學網頁與紙筆評量系統。

## 🌟 教學核心特色
1. **盒子接數法（Counting-on）多感官引導**：
   - **看盒子（首數）**：深藍粗框、淺藍底色，特大字體呈現。點擊盒子主動報讀數值，提醒學生記在腦袋中。
   - **畫圈區（加數）**：虛線長條框，觸控點擊畫圈，具備「➕畫圈」、「➖擦掉」、「✨一鍵畫好」輔助功能。
   - **嘴巴接著數（核心功能）**：圈圈畫好後，點擊圈圈依序發亮並用語音報讀接數（例如：盒子25，依序數26, 27, 28...31），數完引導填寫答案。
2. **漸進式鷹架褪除機制（Scaffolding Fading）**：
   - **第 1 ~ 5 題（鷹架引導階段）**：完整顯示目標圈數進度提示（例如：4/4 個）與防呆提示。
   - **第 6 ~ 20 題（自主挑戰階段）**：完全褪除圈數提示，要求學生自主觀察題目算式自己數圈數，並具備自我檢查（Self-monitoring）溫和引導。
3. **特教多元作答支援**：
   - 螢幕觸控大數字鍵盤 (0~9, ⌫, ✅)
   - 4選1快速點擊選項
   - 實體鍵盤/一般打字
4. **教師課堂與評量**：
   - 👨‍🏫 課堂示範：電子白板一鍵示範接數動畫
   - 🎲 重新出20題：題庫無限隨機出題
   - 🖨️ A4 學習單列印：一鍵列印「學生空白練習卷」或「教師紅字解答卷」，精準兩頁不跑版。
